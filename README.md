# Yuvi-GD
**Technical Architect & Systems Programmer**

</div>

<br/>

Specializing in low level engine architecture, scalable multiplayer networking, and full stack software development. The core engineering focus is bridging the gap between heavy C++ game clients, custom rendering platforms, and modern web backends. By treating software architecture with mechanical precision, the goal is to build robust, modular frameworks that handle everything from highly concurrent server mechanics to native desktop applications.

Operating strictly across game programming, system level software development, and network engineering, the development philosophy prioritizes runtime performance, memory efficiency, and highly extensible developer tooling.

<br/>

### ⚙️ Engineering Domains

* **Systems & Software Architecture:** Building bespoke 3D game engines, ultra lightweight C++ wrappers, and hardware accelerated desktop browsers. Deep focus on C++20, modern rendering pipelines, and low level audio routing.
* **Multiplayer & Network Infrastructure:** Architecting server authoritative logic, custom replication systems, and matchmaking solutions. Extensive implementation of Epic Online Services (EOS), Nakama, and the Unreal Engine Gameplay Ability System.
* **Game Tooling & Plugin Development:** Creating production ready, open source plugins (MP_Manager, MP_Inventory). Transforming complex external SDKs into highly optimized, developer facing Unreal Engine toolkits.
* **Full Stack Integration:** Connecting compiled native applications and game clients to scalable cloud environments using Node.js, Docker, Next.js, and PostgreSQL to engineer robust backend services.
